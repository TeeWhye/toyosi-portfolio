## Running Locally

Clone the repository:


git clone https://github.com/TeeWhye/toyosi-portfolio.git


Navigate into the project:


cd toyosi-portfolio


Install dependencies:


npm install


Start the development server:


npm run dev


The application will be available at:


http://localhost:5173
